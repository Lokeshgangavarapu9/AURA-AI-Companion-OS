# AURA — AI Companion OS

AURA is an intelligent, multi-modal AI Companion OS featuring a 3D VRM avatar, voice interaction, long-term memory engine, and productivity connectors.

## System Architecture

```text
AURA/
├── frontend/        # React + TypeScript + Vite + Three.js + VRM Avatar UI
├── backend/         # Node.js + Express + TypeScript + Prisma + SQLite (Phase 1)
├── memory-engine/   # AI Long-Term Memory & Vector Storage (Phase 2+)
└── docs/            # Architecture documentation & API specs
```

## Quick Start

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
